# デモ設計: Tokyo Sound Walk

> `demo-tokyo/` として新規追加予定の Cesium デモの設計書

---

## コンセプト

外国人観光客に人気の東京スポットを3D地球儀上に配置し、それぞれの場所固有のサウンドを体験できるデモ。  
各スポットにカメラを「飛行」させることで音の変化を楽しめる。

既存の海岸デモが「狭いエリアの詳細音響」を見せるのに対して、このデモは **「東京全域を俯瞰しながら各スポットに飛び込む」** スケール感の大きさを示すことを目的とする。

---

## 新機能（既存デモとの差分）

### 1. テレポートナビゲーションパネル

画面左側に各スポットのボタンを並べ、クリックするとそのスポットへカメラが **スムーズに飛行**（`viewer.camera.flyTo()`）。  
近づくと音が聴こえはじめる体験を演出する。

```
[Senso-ji] [Skytree] [Akihabara] [Shibuya] [Shinjuku] [Odaiba]
```

### 2. スポット情報カード（英語）

カメラがスポット半径 500m 以内に入ったとき、画面右下にカードを表示する。

```
📍 Senso-ji Temple
  Asakusa's iconic Buddhist temple,
  founded in 645 AD.
  🔊 Hear: temple bell, crowds
```

### 3. 広域スケール対応

スポット間の最大距離が約 15km あるため、初期カメラ高度を **10,000m** に設定。  
`cullingDistance: 300` で「近づかないと聴こえない」リアルな体験を維持する。

スケールスライダーを追加し、`setScale()` で **「リアル距離モード」と「圧縮モード」を切り替え** できるようにする。  
これによりライブラリの `setScale()` API を視覚的・聴覚的に示せる。

### 4. 英語 UI

既存デモが日本語 UI なのに対し、このデモは **HTML・ラベルをすべて英語** で作成する。  
外国人観光客向けというコンセプトに合わせる。

## 初期カメラ設定

```ts
// 東京全体が見える高度 10,000m から南南西方向を向く
viewer.camera.setView({
  destination: Cesium.Cartesian3.fromDegrees(139.755, 35.690, 10000),
  orientation: {
    heading: Cesium.Math.toRadians(0),
    pitch:   Cesium.Math.toRadians(-60),
    roll:    0,
  },
});
```
